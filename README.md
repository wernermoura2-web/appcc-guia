# Guia APPCC — Envasadoras RJ

Guia independente de 22 páginas para revisão legislativa, sem banco de dados.

## Publicação

No GitHub Pages, selecionar a branch `main`, pasta `/ (root)`.
O aplicativo abre pelo `index.html`, com três opções: guia HTML, PDF editável e instalação.

## Instalação e isolamento

Identidade permanente: `/appcc-guia/`.
Escopo: `/appcc-guia/`, separado de `/revisao-guia/`.
Ícones APPCC em PNG de 192 e 512 pixels. Manifesto e service worker próprios.
A confirmação da instalação depende do Chrome/Safari e do aparelho.

## Dados

Os campos são salvos localmente. Use Salvar JSON ou exporte o PDF para guardar cópias.
As chaves de armazenamento do guia original foram preservadas para continuidade no mesmo navegador e domínio.
O conteúdo e os cálculos foram mantidos na migração, incluindo fotos, rótulos e edição do PDF.
As referências da proposta de consulta pública devem ser revistas quando a Anvisa publicar o ato definitivo.
